# Contributing to the Mergington High Extra-Curricular Activities Website

Thank you for helping improve the site!

## Development Setup

1. Clone the repository.
2. Install requirements with `pip install -r requirements.txt`.
3. Run the server with `python src/app.py`.
4. Visit `http://localhost:8000`.

## Making Changes

1. Create a branch with a descriptive name, such as `art-gallery-feature` or `fix-chess-signup`.
2. Make and test changes locally with sample student data.
3. Push the branch and create a pull request.
4. Wait for review and address feedback.

## Code Style

- Follow PEP 8 for Python.
- Use clear variable names and comments.

## Need help or have ideas?

- Check the open issues.
- Join the weekly IT Club office hours.
- Email the tech team.
